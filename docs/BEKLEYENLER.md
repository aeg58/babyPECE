# Bekleyenler — dışarıdan beklenen her şey

> Okuma listesindedir. **Boş olması normaldir** — dolduğunda oturum başında görünür.

**Sayaç, istek İLETİLDİĞİNDE başlar** — buraya yazıldığında değil. İletilmemiş bir bekleyiş,
bekleyiş değildir; *"yazdım"* ile *"sordum"* aynı şey değildir.

| # | Kimden | Tam olarak ne | İletildi mi | Gelmezse ne olur | Bu arada ne yapıyoruz |
|---|---|---|---|---|---|
| | | | | | |

**Dört alanın dördü de zorunludur.** *"Gelmezse ne olur"* yazılmamışsa bekleyişin maliyeti
görünmez; *"bu arada ne yapıyoruz"* yazılmamışsa iş sessizce durur.

**Dış tarafa giden mesajı ajan göndermez** — metnini hazırlar, gönderen karşı taraftır.
